🔁 1. Transaction Reconciliation System (Banking Domain)
Problem Statement:
You are given two lists:
List<Transaction> bankTransactions – actual transactions recorded by the bank.
List<Transaction> customerTransactions – transactions recorded by the customer.
Each Transaction contains transactionId, amount, date, and description.
✅ Tasks:
Find all transactions mismatched between the two lists (e.g., different amount, missing in one list).
Group mismatches by reason: "Amount mismatch", "Missing in bank", "Missing in customer".
Generate a Map<String, List<Transaction>> where key is reason, and value is list of mismatches.
Concepts used: filter, groupingBy, map, collect, Optional, equals/hashCode

🧠 2. Employee Hierarchy Analyzer (HR Domain)
Problem Statement:
Given a list of Employee objects, each having id, name, managerId, and salary, perform the following:
Build a hierarchy tree (Manager -> List<Employee>).
Find the total salary burden under each manager (including subordinates recursively).
Identify all managers whose total team salary exceeds a given threshold.
Concepts used: Recursive tree building using Map<Integer, List<Employee>>, Collectors.groupingBy, flatMap, recursion + streams.
